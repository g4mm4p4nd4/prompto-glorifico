## Overview & Purpose

Prompto-glorifico is a safety‑focused project documenting the dependencies and guidelines needed to operate prompt‑based AI tools responsibly. Its purpose is to centralize requirements in one place so that users follow the specified steps exactly, preventing unintended harm when running AI models.

## Features & Tech Stack

### Key Features
- **Safety‑first documentation:** Includes clearly written instructions for operating AI models and emphasizes adherence to best practices.
- **Centralized dependencies:** A single `requirements.txt` file lists all Python packages needed, ensuring a reproducible environment.
- **Easy setup:** Minimal steps to clone, install dependencies, and start using the guidelines locally.

### Tech Stack

| Component | Description |
| --------- | ----------- |
| **Language** | Python |
| **Dependencies** | Packages listed in `requirements.txt` |

## Installation & Usage

Follow these steps to set up the project locally:

```bash
git clone https://github.com/g4mm4p4nd4/prompto-glorifico.git
cd prompto-glorifico
pip install -r requirements.txt
```

After installing the dependencies, open and read the `requirements.txt` file carefully. It contains the precise guidelines that must be followed when using the associated AI tools. There is no executable script; the value of this project lies in the documented instructions.
